# Мои цели на семестр

1. Освоить базовый стек DevOps-инженера: Git, Docker, CI/CD (GitHub Actions), основы Linux (Bash, systemd).
2. Настроить полноценный pet-project с автоматическим деплоем (CI/CD pipeline) и научиться работать с облачной инфраструктурой (Yandex Cloud / Selectel).
3. Изучить основы Infrastructure as Code (Ansible, Terraform) и применить их в собственном учебном проекте.
